# MOE - Mado Operating Extension

![screenshot](docs/screenshot.png)

## 特徴

- Windows 用の軽量なデスクトップマスコット
- インストール不要
- レジストリ不使用

## ダウンロード

https://github.com/imo-systems/moe/releases

## 使用方法

- moe-x.x.x.zip をダウンロード
- zip を任意のフォルダに解凍
- moe.exe を実行
- 不要になったらフォルダごと削除（レジストリは使用しません）

## 動作環境

Windows 10 or later (64 bit)
